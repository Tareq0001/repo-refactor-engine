Capabilities

Enterprise-Grade Features

Every feature a production migration platform needs — from crash recovery to real-time observability.

🧠

Dual-AI Architecture

Claude reads the entire codebase for architectural comprehension. GPT-4 translates each file with that context — a novel approach no other tool offers.

🔌

Plugin Adapter System

Real AST-based parsing for Python, JavaScript, TypeScript, and Java. Extensible registry pattern — add new languages by implementing one interface.

💾

Checkpoint Recovery

Crash mid-migration? Resume exactly where you left off. Every batch is checkpointed to disk with full state serialization.

↩️

Atomic Rollback

Snapshot-based rollback points at every pipeline phase. One command to undo any migration stage with full transaction logging.

📊

Rich Diff Reports

Unified diffs, HTML side-by-side comparisons, and semantic change detection. See exactly what the AI changed and why.

📡

Full Observability

Structured JSON logging, Prometheus-compatible metrics, and OpenTelemetry tracing spans across every operation.

🪝

11-Phase Hook System

Register custom hooks at any pipeline stage — run linters, trigger Slack notifications, apply custom validators, or post-process files.

🌐

Web Dashboard

FastAPI REST API + WebSocket endpoint for real-time browser-based monitoring. Start migrations, track progress, manage rollbacks via HTTP.

💰

Cost Tracking

Automatic API cost estimation per provider. Know exactly how much a migration costs before it finishes. Semantic LRU cache reduces redundant calls.

How It Works

The 5-Phase Pipeline

Each phase is independently testable, hookable, and rollback-safe.

1

Ingest

Clone repo, detect languages, classify files, filter binaries

2

Analyze

Build dependency graph, detect framework, find circular deps

3

Translate

Claude comprehends architecture → GPT-4 translates in topological order

4

Validate

6 integrity checks: imports, orphans, naming, circular deps, completeness

5

Output

Write migrated repo, generate reports, create package manifests
